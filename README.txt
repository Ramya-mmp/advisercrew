ADVISER CREW — LOGO INSPIRED CREATIVE EDITION

QUICK START
1. Extract this ZIP.
2. Open index.html in Chrome or another browser.
3. Edit website text in index.html.
4. Edit colours, spacing and visual effects in css/style.css.
5. Edit interactions in js/script.js.
6. Your supplied logo is in assets/adviser-crew-logo.jpg.

GITHUB PAGES
Upload the contents of this folder (index.html, css/, js/, assets/) to the root of a GitHub repository.
Then open Settings > Pages, choose Deploy from a branch, select main and /(root), and Save.
The contact form is currently a front-end demo and does not send messages.
Bootstrap is loaded from a CDN, so an internet connection is required for Bootstrap styling and the responsive menu.
